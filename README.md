# עולם גירית הדבש 🦡

אתר מעריצים לגירית הדבש: עובדה חדשה פעמיים בשבוע, טריוויה עם לוח מובילים, שני משחקים וקיר סיפורים משותף.

## מבנה

| קובץ | מה יש בו |
|---|---|
| `index.html` | מבנה הדף |
| `style.css` | עיצוב |
| `script.js` | כל הלוגיקה (עובדות, טריוויה, משחקים, קיר, שיתוף) |
| `firebase.js` | חיבור ל-Firestore לקיר הסיפורים וללוח המובילים |
| `facts.js` | 104 עובדות שבועיות (חמישי 09:00 ושבת 20:00) |
| `trivia/` | שאלות הטריוויה לפי נושא. אחרי עריכה מריצים `./build.sh` שבונה את `trivia.js` |
| `firestore.rules` | כללי האבטחה שמפורסמים ב-Firebase |
| `assets/` | הגירית, אייקונים ותמונת השיתוף |

## הוספת שאלות

כל שאלה בקבצי `trivia/` נראית כך — התשובה הראשונה היא תמיד הנכונה, והאתר מערבב את הסדר:

```js
{ q: "השאלה?", a: ["נכונה", "שגויה", "שגויה", "שגויה"], e: "הסבר קצר" },
```

## ניהול הקיר

פוסטים לא רצויים מוחקים ידנית בקונסולת Firebase, תחת Firestore → posts.
